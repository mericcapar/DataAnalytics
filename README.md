# DataAnalytics

My coursework for the **Year Up United Data Analytics Training Academy**. Each folder contains the labs and exercises for that week.

| Folder | Topics |
|---|---|
| `pre-week-1` – `pre-week-3` | Pre-work: getting set up and data analytics fundamentals |
| `week-01` | Excel: descriptive statistics, data cleaning, PivotTables and charts |
| `week-02` | Databases: data types, normalization, ERDs in MySQL Workbench, building a database (Bean & Brew) |
| `week-03` | SQL: SELECT, filtering, sorting, JOINs, aggregate functions, GROUP BY / HAVING, subqueries, scalar functions |
| Week 4 | Capstone 1: SQL and Excel sales analysis. See [Capstone_1](https://github.com/mericcapar/Capstone_1) |
| `week-05` | Python: variables, data types, collections, conditionals and loops |

## Tools
Excel · MySQL Workbench · Python · VS Code · Git & GitHub
